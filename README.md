# Crowdsourced Infrastructure Monitor

A hackathon project for monitoring infrastructure issues through crowdsourced reports.

## Tech Stack
- Mobile App: Flutter
- Backend: FastAPI (Python)
- AI Model: TensorFlow (MobileNetV2 inference)
- Database: MongoDB

## Architecture
Flutter → FastAPI → TensorFlow model → MongoDB

## Setup
1. Backend: `cd backend-api && pip install -r requirements.txt && uvicorn app.main:app --reload`
2. Mobile: `cd mobile-app && flutter run`
3. Model: Train model in model-training/ (placeholder)

## Folders
- `mobile-app/`: Flutter project
- `backend-api/`: FastAPI backend
- `model-training/`: Model training scripts
- `docs/`: Documentation
